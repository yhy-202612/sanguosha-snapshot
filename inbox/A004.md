## 目标

优化对局界面表现力与操作手感。目标文件：`client/style.css`、`client/app.js`（可新增 `client/` 下的资源文件）。

## 白名单

- `client/index.html`、`client/style.css`、`client/app.js`，以及 `client/` 下新增文件
- 不得改 `src/**`（服务端/引擎）

## 需要做到

1. **卡牌视觉**：基本/锦囊/装备三种牌有明显区分（颜色或纹理），花色红黑区分清晰；牌在选中/禁用/可出三态视觉差异明显。
2. **出手动画**：使用牌时有一张「飞到桌面中央」的过渡（纯 CSS transition/keyframes，不引入库）。
3. **受击反馈**：`state` 里某玩家 hp 下降时，其卡片闪红 + 震动 300ms。
4. **回合高亮**：当前回合玩家有明显光晕，并在顶栏显示阶段进度条（准备→判定→摸牌→出牌→弃牌→结束）。
5. **操作提示**：出牌阶段若选中牌后没有可用目标，给出文字提示（如「该牌需要选择目标」）。
6. **移动端**：宽度 < 420px 时手牌改为可横向滑动、按钮不换行溢出；`#askPanel` 不遮挡手牌。
7. **战报时间轴**：日志按回合分组显示「第 N 回合」为分隔线。
8. **无外部依赖**：不得使用 CDN、npm 包、外部图片（图标用 emoji 或内联 SVG）。

## 验收标准

1. `node tools/selfcheck.js` → 失败 0（前端不影响引擎，但要保证没改坏服务端）。
2. `node --check client/app.js` 通过（语法合法；ESM 会警告 `--check` 对 module 的支持，用 `node --input-type=module --check < client/app.js` 替代亦可）。
3. 页面在 1920×1080 与 390×844 两种尺寸下无横向滚动条、无元素重叠（自查描述写进报告）。
4. 不修改接口字段名（前端读取的 snapshot 字段必须与服务端一致）。

## 备注

- 服务端下发的字段见 `src/engine/game.js` 的 `snapshot()`。
- 交互契约：出牌阶段 `S.ask.kind === 'play'`，选牌 → 选目标 → `submit({cardId, seats})`；响应 `kind = 'card'` 时只能出 `ask.cards` 里的牌。
