# A007 · 连通性探针（PING · 零改动）

> 这是一张**纯探针单**：目的只有一个 —— 确认你现在真正连的是哪条通道。
> **不要修改任何文件、不要创建分支、不要提交代码、不要跑构建或压测。** 只做只读检查并写一份回执。

## 1. 执行步骤（全部只读）

1. 确认你当前工作目录的绝对路径。
2. 执行 `git remote -v` 与 `git rev-parse HEAD`，记下远端地址与当前提交。
3. 执行 `git rev-parse --abbrev-ref HEAD` 记录当前分支。
4. 记录本机时间（含时区）与 `node -v`。
5. 执行 `ls inbox` 列出你看到的任务单编号。

## 2. 回执（必须一字不差地用这几行开头）

写到 `reports/A007.md`（调度脚本会写回 `dsh/reports` 分支）：

```
RESULT: done
TARGET_REPO: <你执行 git remote -v 得到的仓库全名，例如 yhy-202612/sanguosha-online 或 yhy-202612/zhihui-showcase>
WORKDIR: <工作目录绝对路径>
BRANCH: <当前分支名>
HEAD: <git rev-parse HEAD 的前 8 位>
PONG: <本机时间，ISO 8601 带时区>
INBOX: <ls inbox 看到的任务单编号，逗号分隔>
```

`RESULT` 后可选写一段摘要，但**不得**包含代码改动。

## 3. 判定规则（你自己先判断一次，写在摘要里）

- 若 `TARGET_REPO` 是 `yhy-202612/sanguosha-online` → 写 `CHANNEL: OK`，任务结束。
- 若 `TARGET_REPO` 是别的仓库 → 写 `CHANNEL: MISMATCH`，并说明「轮询仍指向旧仓库，需要把 `--repo` 改成 `yhy-202612/sanguosha-online`」。

## 4. 如果 clone 失败或没有权限

不要尝试任何绕过手段。直接把 `RESULT: blocked` 与错误原文写进回执（此时可能写不进仓库，那就把错误留在你的终端输出里）。
