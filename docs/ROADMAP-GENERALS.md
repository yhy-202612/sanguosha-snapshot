# 三国杀在线 · 武将扩展路线图（v1，2026-10-24）

## 0. 基线（动手前必须记住的事实）

**现有武将 77**：standard 25 / jie（界限突破）25 / mou（谋）10 / shen（神）12 / ji（极）5。

**引擎已具备**：判定与改判、marks 标记、横置 chain、护甲 armor、觉醒技、限定技、双将合并（hp 取平均向上取整、护甲求和）、托管、拼装式 defineSkill（40 个事件钩子）。

**引擎缺口（已 grep 确认无实现）**：拼点、翻面、转换技、双势力/双形态、宗族技、勾玉颜色、装备区占领、隐匿技、技能失效、额外回合、不屈牌堆、质疑（蛊惑）、化身。

**两个必须知道的结构性陷阱**：
1. `getSkill()` 有前缀降级：`jie_/mou_/ji_` 前缀技能未实装时会**静默复用标准包同名技能**（历史事故：界孙权实际在跑标准孙权）。新增扩展包**不得**使用这三个前缀，且每批必须校验「无 fallbackOf」。
2. AI 主动技是 `src/ai/index.js` 里的**硬编码 if 链**（按 `baseSkillId`）。新主动技不加进去 = AI 永远不发动（历史事故：界/谋/极全部不发动）。

## 1. 机制路线图 M1–M12（全盘关键路径）

先落机制、再批武将；机制不齐时对应武将一律顺延，不硬写。

| 编号 | 机制 | 最小实现要点 | 落点 | 首次被谁依赖 |

| M4 | 双势力 / 入魔形态 | `player.kingdom2` + `player.form`（normal/demon），按 form 切技能组 | engine/game.js | 族诸葛诞、闪张辽、魔系列 |
| M5 | 宗族技 | `player.clan` 标签 + `sameClan()`；宗族技本身为共享技，同族角色均持有 | data/generals.js + skill | 门阀士族全系 |

| M7 | 装备区占领 | `player.occupied[slot]`，被占领槽不可换装、不计距离 | engine/game.js | 线下 蚀心入魔 丁原 |

| M9 | 不屈牌堆 | `player.buqu[]`；濒死时翻牌堆顶比较，重复则移除 | engine/game.js | 风包 周泰【不屈】 |
| M10 | 质疑（蛊惑） | 多阶段询问：全体可质疑 → 亮牌 → 按真假结算奖惩 | engine/game.js | 风包 于吉【蛊惑】 |

## 5. 风险与守门条款

1. **禁止静默降级**：新包技能漏实装会被 `getSkill` 兜底成标准包同名技能，且不报错 → 门禁 2 必须硬卡 `fallbackOf === undefined`。
2. **AI 白名单**：新主动技必须进 `ai/index.js`，否则「玩家能发动、AI 从不发动」，对局观感异常。
3. **confirm 类续发陷阱**：界青囊曾因「无限再发动」导致 568 回合僵局。任何「是否再次发动」的询问，AI 侧必须限频（hand ≥ 5 且 ≤35% 概率）。
4. **双将适配**：新将若带护甲，双将合并时护甲求和、hp 取平均向上取整（已实现），需在 regression 补断言。
5. **平衡分档**：每批上线前对 3–5 个「强将」标注强度（S/A/B），simulate 观察主公胜率偏差 >15% 则回调。
6. **每批 ≤25 将**：一次改动过大导致回归定位困难（历史教训：一批 40 将时无法二分定位）。

### 17.1 音效层 v2（`client/audio.js` 165 → 550 行）

### 19.2 自查出的第 6 条：`cards.lose` 是死事件

`cards.lose` 在 `VALID_EVENTS` 白名单里，但**引擎从不 emit**（全仓 `grep` 只有注册与唯一一处监听）。监听它的【沙城】（转·娄圭）第二触发器负责统计「目标本回合失去的牌数」，因此该统计恒为 0 → 沙城摸牌数永远是 0，技能一半失效。

修法：在三条真实「失去牌」路径补 emit（口径 = 牌离开该角色的手牌/装备区/判定区）：

- `discardCards` 末尾（排除 `kept` 的牌）
- `gainCards` 且 `from` 非空（被其他角色获得）
- `takeCard`（记录 owner 后逐个 emit）

「使用牌」不算失去（`useCard` 走 `pushDiscard`，不经过上述三处），口径与官方一致。顺带解决 `xinghuo2.js` 里「引擎不触发 cards.lose」的绕行注释。
